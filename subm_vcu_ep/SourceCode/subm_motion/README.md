# Motion Submodule

## Description

This repository is easy-to-integrate result of [VCU Motion repository](http://es36/root/kmc_vcu_ep_motion_simulink_code) generated codes.

There is two main folders

1. include: Contains header files generated or used by Simulink / Embedded Coder

2. source: Contains source code files generated or used by Simulink / Embedded Coder

## Usage

This submodule integrates with `VCU` main project files.

## Rules

Keep things as Simulink create; No man-made-change allowed!

> Note **Apply ANY changes in *Simulink Project* ONLY**
